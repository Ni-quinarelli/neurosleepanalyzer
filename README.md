# Overview

NeuroSleep Analytic is a web-based platform developed to support automated analysis, visualization and interpretation of sleep-related physiological data.

The platform was designed as part of a scientific research initiative focused on the development and validation of computational tools for sleep stage recognition using artificial intelligence and machine learning techniques.

NeuroSleep Analytic simplifies the processing of complex datasets by providing automated statistical analysis, graphical visualization, descriptive metrics, report generation and AI-assisted interpretation.

The system aims to facilitate research workflows, increase reproducibility and improve accessibility to advanced data analysis methods for researchers, students and healthcare professionals.

# Research Context

This software is associated with the scientific project:

**"Validation of an Automated Visual Recognition Tool for Sleep Stage Classification Using International Public Polysomnography Databases"**

The project investigates computational approaches for automated classification of sleep stages (Wake, N1, N2, N3 and REM) using artificial intelligence models trained on publicly available polysomnography datasets.

The long-term objective is to contribute to the development of reproducible and accessible technologies capable of supporting sleep research and future clinical applications.
